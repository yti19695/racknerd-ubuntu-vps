## 1 GB 内存够不够用

跑轻量负载够用，跑重型容器化应用不够。Ubuntu Server 空载就要吃掉两三百 MB，1 GB 机器实际可用大概六七百 MB。用 apt 装 Nginx、PHP-FPM 或一个 Node 应用，配 1–2 GB swap，个人博客和小 API 完全跑得动。Snap 方式安装的重型应用（Nextcloud、GitLab 这类）在 1 GB 上会很吃力，这类需求要么改用 apt 或 Docker 装更轻的版本，要么直接上 2.5 GB 档。
